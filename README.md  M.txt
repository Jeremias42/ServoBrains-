Proyecto Arduino: LED parpadeanteEste proyecto enciende y apaga un LED cada 1 segundo usando una placa Arduino.Materiales1 Arduino Uno1 LED1 resistencia de 220 ohmiosCables jumperProtoboardConexiónConecta el ánodo del LED al pin 13.Conecta el cátodo a GND usando la resistencia.Archivos del proyecto`MiProyecto.ino``README.md`Cómo usarloAbre el archivo `.ino` en Arduino IDE.Conecta tu placa Arduino al computador.Sube el código a la placa.Observa cómo el LED parpadea.CódigoEl código principal está en el archivo `.ino`.cambio localmente
